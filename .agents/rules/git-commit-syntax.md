# Git Commit Message Convention

Whenever creating a Git commit for this repository, you MUST strictly format the commit message starting with the user's name:

- For additions: `[Amit Kumar Rai]. added <description of what was added>`
- For updates / modifications: `[Amit Kumar Rai]. updated <description of what was updated>`
- For deletions / removals: `[Amit Kumar Rai]. deleted <description of what was removed>`
- For bug fixes: `[Amit Kumar Rai]. fix <description of what was fixed>`

Example:
`[Amit Kumar Rai]. added full end-to-end Razorpay payment gateway integration across gateway, docker, and frontend`
